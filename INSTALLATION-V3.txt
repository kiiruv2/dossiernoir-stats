DOSSIER NOIR STATS V3 — INSTALLATION

1) SAUVEGARDE
- Dans GitHub, télécharge une copie de la V2 ou crée une branche `backup-v2`.

2) REMPLACEMENT
- Décompresse ce ZIP.
- Remplace tous les fichiers du dépôt `dossiernoir-stats`.
- Commit sur la branche `main`.
- Vercel lancera un nouveau déploiement Production.

3) VARIABLES VERCEL
Conserve :
YOUTUBE_API_KEY
YOUTUBE_CHANNEL_ID

Ajoute :
CRON_SECRET = une longue valeur aléatoire

Facultatif pour l'IA :
OPENAI_API_KEY
OPENAI_MODEL = gpt-5.6-mini

4) SUPABASE
- Crée un projet gratuit sur Supabase.
- Ouvre SQL Editor.
- Exécute `supabase/schema.sql`.
- Ajoute dans Vercel :
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY

5) INSTAGRAM
- Nécessite une application Meta et les permissions Instagram Insights.
- Le compte doit être Créateur ou Business.
- Les métriques Reels ne peuvent être automatisées qu'après autorisation.
- En attendant, utilise `/admin`.

6) TIKTOK
- Nécessite une application TikTok for Developers.
- Active Login Kit et Display API.
- Demande les scopes nécessaires, notamment la lecture du profil/vidéos.
- En attendant, utilise `/admin`.

7) ALERTES
- La V3 calcule et affiche les alertes internes.
- Pour recevoir une notification sur téléphone, ajoute ensuite un canal :
  Discord webhook, Telegram bot ou email.
- Les webhooks ne sont pas inclus tant que tu n'as pas choisi le canal.

8) DONNÉES YOUTUBE AVANCÉES
La clé publique récupère vues, likes, commentaires et miniatures.
Pour la rétention, la durée moyenne et les abonnés gagnés par vidéo,
il faudra connecter YouTube Analytics via OAuth Google.

9) MODE DÉMO
Le bouton Mode démo affiche des données fictives seulement quand aucune donnée réelle n'existe.
Désactive-le pour voir uniquement les données réelles.
